# Development Guide

## Linting

We use [Ruff](https://docs.astral.sh/ruff/) for linting:

```bash
ruff check .
```

## Formatting

```bash
ruff format .
```

## Type Checking

```bash
pyright
```

## Tests

```bash
pytest
```

## Contribution Notes

- Use meaningful commit messages
- Follow code style conventions
- Write tests for new functionality
